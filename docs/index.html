d-rum-testing-gpu

Testing Random Utility on the GPU

The code of the paper's algorithms. It measures how far observed choice probabilities p̂ are from the random utility (RUM) polytope, with a certified bracket lb ≤ dist ≤ ub, and tests H0: dist = 0 with Hong and Li's bootstrap. Three methods run on an NVIDIA GPU, four on the CPU with Gurobi, and every table of the paper can be rebuilt from the data in the repository.

1What it computes

The data are choice probabilities p̂(a | D): how often alternative a was chosen from menu D, on the observed (menu, alternative) cells. A random utility model is a probability distribution over rankings of the alternatives, and the choice probabilities it can produce form a polytope. The distance dist(p̂) = min ‖p − p̂‖ over the points p of that polytope is 0 exactly when the data are consistent with some random utility model.

Every method returns a bracket lb ≤ dist(p̂) ≤ ub, not an estimate: ub is the distance of an exactly feasible RUM point, and lb comes from a certificate (a Frank–Wolfe bound, or the pricing integer program's bound). The bootstrap builds Hong and Li's test of H0: dist = 0 on top of those brackets, so its p-value and intervals are certified too.

3Install

pip install -r requirements.txt     # numpy, scipy, numba, pandas
  • GPU methods (BM-ADMM, Flow-CG, Flow-ADMM): an NVIDIA GPU and the CuPy wheel that matches your CUDA driver, cupy-cuda12x or cupy-cuda13x.
  • CPU methods (IP-CG, IP-H-CG and the two exact QPs, which are also the choice when there is no GPU): gurobipy and a Gurobi licence.
  • Python 3.10 or later; the paper's runs used Python 3.12.

4Quick start

import pandas as pd
from solver.rum_solver import RUM

# cd ("choice data") holds the observed choice probabilities, one row per (menu, alternative) pair:
#   menu  the offered menu, a bitmask over the alternatives 0..n-1 (bit a set = alternative a offered)
#   alt   an alternative in the menu
#   phat  the observed probability of choosing alt from the menu
n = 18                                  # the number of alternatives
cd = pd.read_csv("final_data/Numerical1/raw_data/n18_d1pct.csv").to_numpy()
rum = RUM.from_rows(cd, n)
res = rum.calculate_distance()          # automatic method; stops at abs 1e-5 or rel 1e-4; 1 h cap
print(res.lb, res.ub, res.exit_flag)

The test of RUM needs the choices behind p̂, one row per choice:

import pandas as pd
from solver.inference import cells_from_panel

panel = pd.read_csv("final_data/Application_DSR/raw_data/overload_data_25_long.csv")
menu, alt, p_hat = cells_from_panel(panel, 25, alternatives=[0])
rum = RUM(menu, alt, p_hat, num_alternatives=25)
print(rum.bootstrap(panel=panel).p_value())   # p = 0.1083
